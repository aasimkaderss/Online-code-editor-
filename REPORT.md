# Online Code Editor with Live Preview

## Introduction
The Online Code Editor is a web-based mini IDE that allows users to write HTML, CSS and JavaScript directly in the browser and immediately view the output. It is based on the internship project idea “Online Code Editor with Live Preview,” whose objective is to create a browser-based IDE for HTML, CSS and JS. ## Abstract
The application provides a simple coding environment with separate editors for HTML, CSS and JavaScript. Monaco Editor is used for code editing, while a sandboxed iframe displays the live result. Users can load templates, reset their work, switch between dark and light themes, and generate a shareable URL containing the current code.

## Tools Used
- React.js – user interface and state management
- Vite – development and build tool
- Monaco Editor – browser-based code editor
- HTML5 – page structure
- CSS3 – styling and responsive layout
- JavaScript – application logic and live preview

## Steps Involved in Building the Project
1. Created a React + Vite project structure.
2. Added Monaco Editor for HTML, CSS and JavaScript editing.
3. Created separate tabs for the three languages.
4. Stored editor content in React state.
5. Combined HTML, CSS and JavaScript into a complete document.
6. Displayed the result using a sandboxed iframe for live preview.
7. Added starter and profile-card templates.
8. Added reset, theme switching and share-link features.
9. Added responsive styling for smaller screens.
10. Tested editing and preview behavior.

## Conclusion
The project demonstrates the basic working of an online coding environment. It provides instant feedback while writing front-end code and gives practical experience with React components, state management, browser rendering and responsive UI design. Future improvements can include cloud snippet storage, user authentication, code sharing through a database and more templates.
